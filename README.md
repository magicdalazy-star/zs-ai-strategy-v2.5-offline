## 下载离线包

从 [最新 Release 下载完整离线包](https://github.com/magicdalazy-star/zs-ai-strategy-v2.5-offline/releases/latest/download/ZS_AI_Strategy_V2.5_Offline_20260914_1420.zip)，完整解压后：

- Windows：运行 `START_WINDOWS_CHROME.bat`。
- macOS：运行 `START_MAC.command`，或用 Chrome 打开 `presentation/index.html`。
- 方向键、空格、PageUp/PageDown 翻页；`F` 全屏，`S` 显示讲者备注，`O` 打开总览。

离线包中的演示稿本体和视频可离线使用。MaaS、AI 菜单及 AI 标书入口需要联网；青峰管家入口尚未配置。
